# Русско-японская война 1904–1905 гг.

## 1. Структура проекта

```
history_rus-jap_war-main/
│
├── index.html                 # Главная HTML-страница приложения
│
├── scripts/                   # JavaScript-модули
│   ├── main.js               # Основная логика: тест и анимации
│   ├── navigation.js         # Навигация и мобильное меню
│   └── theme.js              # Управление темной/светлой темой
│
└── styles/                    # CSS-стили
    ├── main.css              # Основные стили приложения
    ├── responsive.css        # Адаптивные стили для мобильных устройств
    └── theme.css             # Стили для темной темы
```

### 2.1. Адаптивность
- Mobile-first подход через медиа-запросы
- Гибкие сетки (CSS Grid) с автоматической адаптацией
- Мобильное меню с плавной анимацией

### 2.2. Производительность
- Скрипты загружаются в конце `<body>`
- Использование CSS-переменных для быстрого переключения тем
- Оптимизированные анимации через CSS transitions

### 2.3. Доступность
- Семантические HTML-теги
- Плавная прокрутка для навигации
- Визуальная обратная связь при взаимодействии

### 2.4. UX/UI
- Темная/светлая тема с сохранением выбора
- Плавные анимации и переходы
- Интерактивный тест с визуальной обратной связью
- Временная шкала для визуализации исторических событий

---
